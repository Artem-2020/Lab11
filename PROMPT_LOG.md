## Задание №9: Ограничение ресурсов контейнеров

### Промпт 1
**Инструмент:** Codex  
**Промпт:** "Добавь ограничение ресурсов для контейнеров Python и Rust. Подготовь `docker-compose.yml`, где для каждого сервиса указаны лимиты CPU, памяти, swap и количества процессов. Для Python задай `0.50` CPU и `128m` памяти, для Rust — `0.50` CPU и `64m` памяти. Также добавь команды запуска контейнеров с такими же лимитами через `docker run`."  
**Результат:** Создан `docker-compose.yml` с параметрами `cpus`, `mem_limit`, `memswap_limit` и `pids_limit`. В README добавлены команды запуска через Docker Compose и через обычный `docker run`.
